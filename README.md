# HORDE
A simple top-down 2D Java game that is directly inspired by the Call of Duty zombie mode.
Players attempt to survive increasingly difficult waves of the undead as they earn progression
rewards to improve their chances of survival. Bring a buddy into the fight to improve your 
odds using LAN multiplayer!

## Features
- Round-based zombie survival
- LAN multiplayer
- Player progression
- Zombie pathfinding
- Combat
- Tiled map system
- Simple animations
- Player customization
- Music and sounds
- In-game visual effects

## Controls
Mouse left click - shoot primary gun
Mouse right click - shoot secondary gun (when dual-wielding)
Mouse scroll up/down - switch weapon
E - switch weapon
W - move up
A - move left
S - move down
D - move right
V - melee
G - throw grenade (can hold to cook)
Q - throw special grenade (if equipped)
ESC - pause game (if solo; if multiplayer, would only prompt the menu)


## Tech Stack
- Programming Language: Java 17
- Graphics: Java AWT
- Build Tool: Maven
- Networking: KryoNet
- JSON Parser: Jackson
- Map Editor: Tiled
- Version Control: Git
